## 2. The Signer Interface (from types.ts)

```typescript
export interface Signer {
  getAddress(): Promise<EvmAddress>;
  signTypedData(data: TypedDataPayload): Promise<EvmSignature>;
  signMessage(message: string): Promise<EvmSignature>;
  sendTransaction(request: SignerTransactionRequest): Promise<TransactionHandle>;
}
```

## 3. Files to Create

### 3a. `packages/client/src/openfort.ts` — main entrypoint

Mirrors `privy.ts` exactly. Structure:

1. **Imports:** `process` from `node:process`, `invariant` from `@polymarket/types`, error classes from `./errors`, `Signer` and related types from `./types`, `Openfort` class from `@openfort/openfort-node`
2. **Node Runtime Guard:** `invariant(process.release.name === 'node', '...')` and `invariant(typeof window === 'undefined' && typeof document === 'undefined', '...')`
3. **Config Type:** `OpenfortWalletConfig = { openfort: Openfort; accountId: string; policy?: string; }`
4. **Main Export:** `signerFrom(config: OpenfortWalletConfig): Signer`
5. **Signer Implementation:** Implements all 4 methods using `openfort` instance:
   - `getAddress()` → `openfort.getEVMAccount(config.accountId).then(a => a.address)`
   - `signTypedData(data)` → lookup account's signer, sign typed data
   - `signMessage(message)` → lookup account's signer, sign message
   - `sendTransaction(request)` → use Openfort's `sendTransaction` action, build `TransactionHandle`
