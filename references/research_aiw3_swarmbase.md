## AIW3 (Web3 Agent-as-a-Service Platform)

### Official Sources
- **Official Website**: https://aiw3.ai (Next.js app, client-side rendered; Solana-focused)
- **GitHub**: https://github.com/AIW3 — org exists but no public repos visible
- **X/Twitter**: @AIW3_AI (identified via airdrops.io references)
- **Backers**: GalaXin Capital, LD Capital, 0G, Panga Capital, Buffalo Capital, Three-stones Ventures

### Verified Dates
- **Snapshot (Genesis Snapshot)**: July 28, 2026 ✅ CONFIRMED
- **Eligibility Checker**: July 29, 2026 ✅ CONFIRMED
- **TGE (Token Generation Event)**: August 3, 2026 ✅ CONFIRMED
- Monthly airdrop rounds continue after TGE

### Chains
- **Solana** (primary — confirmed via meta tags: "AI Agent management, token trading, and social features on Solana blockchain")
- **BNB Chain** (also supported — confirmed via airdrops.io: "The platform runs on Solana and BNB Chain")
- Also integrates OKX OAuth for wallet/auth

### Wallet & Funds Requirement
- **Requires wallet connection**: YES — wallet binding required before snapshot (by July 28)
- **Free tasks**: Daily check-ins (3-10 pts/day scaling), community tasks (follow X, repost, join Telegram — 10-20 pts each), daily predictions (20 pts/day, 50 for 3), referrals
- **Paid tasks**: Trading volume (points per 1,000 USDT volume) — requires real capital
- Strategy publishing needs time, not money
- Anti-Sybil screening enforced

### Platform Description
AI Agent management + token trading + prediction markets on Solana/BNB Chain. Users build/backtest/deploy AI trading strategies, manage vaults.

## SwarmBase (AI Agent Infrastructure on BNB Chain/opBNB)

### Official Sources
- **Official Website**: https://swarmbase.io (React app — "The Cognitive Backbone of Agentic Swarms")
- **X/Twitter**: @SwarmBase (verified via meta tags: twitter:site = @SwarmBase)
- **GitHub**: https://github.com/SwarmBase — has `swarmbase` repo (24 stars, described as "peer-to-peer dweb database with access control")
- **Backers**: Castrum Capital, M2M Capital, Notch Ventures, Becker Ventures
- **Total Raised**: $7 million (including $4M follow-on in July 2026)
- **Contract**: EmergentAgent / emergent.sh infrastructure

### Airdrop Status
- **Confirmed Airdrop**: YES ✅ — 20% of 1 billion $SWARM supply reserved for community
- **TGE Date**: NOT published yet (described as "upcoming")
- **Snapshot**: Before TGE (exact date not published); sybil filtering applied
- **Vesting**: 50% unlocks at TGE, rest vests over time

### Point System (SwarmScore)
- **On-chain SwarmScore** (opBNB, chain ID 204):
  - Registration (on-chain tx)
  - Daily check-ins (base 10 pts, streak multiplier up to 3x, from day 30: 30 pts/day)
  - Soulbound badges: Pioneer (early registrants), Builder (platform activity), OG (priority allocation at TGE)
  - Referrals: 10 pts immediate + milestone bonuses (up to 860 pts per referral)
- **Off-chain Task Credits**: Use SwarmCore AI agents for research/analysis tasks
- Both combine into total allocation

### Wallet & Funds Requirement
- **Requires wallet connection**: YES — MetaMask or EVM wallet (auto-adds opBNB network)
- **Requires BNB for gas**: YES — every action is an opBNB transaction; gas is fractions of a cent but real BNB needed
- **Registration**: On-chain transaction (gas fee required)
- **No minimum invite requirement**: Anyone can register without invite
- **Bridge widget available**: For moving funds from other chains to opBNB

### Chains
- **BNB Chain** (core infrastructure layer)
- **opBNB** (engagement layer — chain ID 204 — all user interactions)

### Platforms Used
- PostHog analytics (phc_yJW1VjHGGwmCbbrtczfqqNxgBDbhlhOWcdzcIJEOTFE)
- EmergentAgent / emergent.sh for hosting
- Tailwind CSS, React (CRA)

### Notes
- **swarmbase.xyz** is a *different service* — a Chinese AI API Gateway / subscription platform (not the official SwarmBase project)
- The official SwarmBase website has no dedicated docs/whitepaper page (returns 404 on /whitepaper)
